# 🎀 Bellemi — Pequenos encantos, grandes brilhos.

**Bellemi** é uma loja virtual de maquiagem, skincare e produtos de beleza, desenvolvida com o objetivo de proporcionar uma experiência de compra agradável, intuitiva e organizada.

O projeto combina tecnologia, criatividade e uma identidade visual delicada, inspirada no universo da beleza e do romantismo.

---

## 🌷 Sobre o projeto

A Bellemi é um projeto de desenvolvimento web que simula o funcionamento de um e-commerce de produtos de beleza.

A plataforma permite a organização de produtos por categorias, navegação pelo catálogo, gerenciamento de carrinho e desenvolvimento de funcionalidades relacionadas ao processo de compra.

Além da experiência do cliente, o sistema conta com uma área administrativa destinada ao gerenciamento das informações da loja.

## ✨ Funcionalidades

### 🛍️ Área do cliente
- Cadastro e login de usuários.
- Navegação pelo catálogo de produtos.
- Visualização de produtos por categorias e subcategorias.
- Pesquisa e filtros de produtos.
- Ordenação de produtos.
- Adição e remoção de produtos do carrinho.
- Gerenciamento de pedidos.
- Seleção de opções de pagamento.
- Integração com pagamento via Pix.
- Consulta de opções de frete.

### 💻 Área administrativa
- Gerenciamento de produtos (CRUD).
- Gerenciamento de funcionarios.
- Gerenciamento de clientes.
- Gerenciamento de pedidos.
- Gerenciamento de devoluções.
- Organização e controle das informações da loja.

## 🗄️ Banco de dados

O projeto utiliza PostgreSQL para armazenar e organizar as informações da aplicação.

Entre as principais entidades do banco de dados estão:

- PESSOA
- CATEGORIA
- PRODUTO
- FORNECEDOR
- PRODUTO_FORNECEDOR
- PEDIDO
- ITEM_PEDIDO
- PAGAMENTO
- FRETE_ESTADO

As tabelas são relacionadas para garantir a organização e a consistência das informações.


## 🎀 Identidade visual

A identidade visual da Bellemi foi desenvolvida com inspiração no romantismo, na delicadeza e na feminilidade.

A proposta visual utiliza:
- Tons suaves e paleta de cores pastel.
- Elementos florais e laços.
- Detalhes delicados e acabamento visual elegante.
- Uma interface pensada para proporcionar uma navegação intuitiva.

**Slogan:** Pequenos encantos, grandes brilhos.

O projeto foi desenvolvido como parte das atividades do curso Técnico em Informática, com o propósito de aplicar conhecimentos de desenvolvimento web, programação, integração entre front-end e back-end e modelagem de banco de dados.

A Bellemi representa a aplicação prática dos conhecimentos adquiridos durante a formação técnica.
